# Hârtie Milimetrică

Joc creativ de desenat în browser, pe hârtie milimetrică (1 pătrățel = 1 mm).

- Colorează pătrățele cu creionul, radiera, găleata și pipeta
- Paletă vastă de culori + selector complet de culoare
- Zoom in / zoom out, încadrare foaie
- Descărcare PNG / JPEG: toată foaia, doar desenul sau o zonă marcată cu un dreptunghi
- Salvare automată în browser + salvare/deschidere proiect (.json)

Site static (un singur `index.html`), găzduit pe Cloudflare Pages.
